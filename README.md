### Setup Instructions

#### Prerequisites
- Node.js 18+
- Expo Go app on phone
- Git

#### Installation
\\\ash
# Clone the repository
git clone https://github.com/git-user01nf/UNAM-I3691CP-WaterLeak-Ongwediva.git

# Install dependencies
cd UNAM-I3691CP-WaterLeak-Ongwediva
npm install

# Start the app
npx expo start
\\\
